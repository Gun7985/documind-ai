# 배포 검증 및 종료 체크리스트

이 체크리스트는 짧은 실제 배포 기간 동안 E2E 검증과 증빙 수집을 완료한 뒤 모든 임시 공개 경로와 자원을 안전하게 종료하기 위한 것이다. 실제 비밀값이나 사용자 PDF는 증빙에 포함하지 않는다.

## 배포 구성과 경계

- 클라우드에는 React 정적 웹 애플리케이션과 유일한 공개 API인 Spring Boot를 배포한다.
- Supabase Auth, PostgreSQL 및 private Storage를 사용한다. 브라우저에는 공개 가능한 anon/publishable key만 제공한다.
- 사용자 Windows PC에서 FastAPI, PyMuPDF 및 Ollama를 실행한다.
- 클라우드 Spring Boot와 로컬 FastAPI는 인증된 보안 터널을 통해서만 통신한다.
- FastAPI와 Ollama는 공용 인터넷에 직접 공개하지 않으며, 터널이 Ollama로 직접 연결되는 경로도 만들지 않는다.
- 특정 클라우드 제공자, 터널 제품 및 Ollama 모델은 검증 전 확정하지 않는다.

## 배포 전

- [ ] 클라우드 React와 Spring Boot의 후보 환경 및 공개 URL 구성을 확인했다.
- [ ] 사용할 호스팅과 인증된 보안 터널의 설정 및 비용을 확인했다.
- [ ] 운영용 비밀값은 Git 외부의 안전한 비밀 저장소에 설정했다.
- [ ] Supabase Auth와 PostgreSQL의 사용자 격리 정책을 확인했다.
- [ ] Supabase Storage 버킷이 비공개이며 사용자별 서버 권한 검사가 적용됐다.
- [ ] 사용자 Windows PC에서 FastAPI와 Ollama가 필요한 계정과 최소 권한으로 실행된다.
- [ ] FastAPI와 Ollama가 공용 인터넷에 직접 노출되지 않음을 확인했다.
- [ ] Spring Boot에서 FastAPI로의 요청이 터널 인증과 애플리케이션 계층 인증을 모두 통과한다.
- [ ] 테스트용 계정 두 개와 민감정보가 없는 텍스트 기반 샘플 PDF를 준비했다.

## E2E 검증

- [ ] 공개 URL에서 React 애플리케이션에 접속할 수 있다.
- [ ] 테스트 사용자가 로그인 및 로그아웃할 수 있다.
- [ ] 허용 범위의 PDF를 업로드하고 목록과 상세에서 확인할 수 있다.
- [ ] AI 분석이 `PENDING` → `EXTRACTING` → `ANALYZING` → `COMPLETED`로 진행된다.
- [ ] 요약, 핵심 포인트 및 키워드가 표시된다.
- [ ] 제목 수정, 삭제, 재분석 및 분석 이력 조회가 동작한다.
- [ ] 제목/키워드 검색과 상태 필터가 동작한다.
- [ ] 두 번째 사용자가 첫 번째 사용자의 문서 URL 또는 ID로 데이터에 접근할 수 없다.
- [ ] 로컬 AI 서버 또는 보안 터널을 중단했을 때 분석이 제한된 재시도 후 `FAILED`가 되고 안전한 사용자 메시지를 표시한다.
- [ ] 크기, 페이지 수 또는 형식 제한을 위반한 업로드가 거부된다.

## 증빙 수집

- [ ] 공개 URL 접속과 주요 사용자 흐름의 화면을 캡처했다.
- [ ] 성공한 분석 상태 및 결과를 캡처했다.
- [ ] 검색, 이력, 사용자 간 접근 차단 및 AI 서버 장애 처리 결과를 기록했다.
- [ ] 배포 버전 또는 커밋 식별자와 검증 일시를 기록했다.
- [ ] 캡처와 로그에서 토큰, 키, 개인 데이터 및 사용자 PDF 내용을 제거했다.

## 서비스 종료

- [ ] 클라우드 React와 Spring Boot 서비스를 중지하거나 삭제했다.
- [ ] 인증된 보안 터널을 종료하고 공개 엔드포인트가 닫혔음을 확인했다.
- [ ] 로컬 FastAPI와 Ollama 프로세스를 종료했다.
- [ ] 임시 배포에 사용한 키와 토큰을 폐기 또는 회전했다.
- [ ] 테스트 사용자, 업로드 PDF, 분석 결과 및 기타 임시 데이터를 삭제했다.
- [ ] 임시 호스팅, 터널 및 데이터베이스 자원의 과금이 중단됐음을 확인했다.
- [ ] 공개 URL과 API에 더 이상 접근할 수 없음을 외부 네트워크에서 확인했다.
- [ ] 보존할 증빙을 안전한 위치로 옮기고 민감한 임시 로그와 로컬 파일을 삭제했다.

## 검증 필요

- **클라우드 호스팅:** React와 Spring Boot 제공자, 리전, 비용, 로그 보존 및 종료 절차
- **보안 터널:** 제품, 상호 인증 또는 동등한 인증 방식, 접근 정책, 키 회전과 폐기 절차
- **Ollama 모델:** 모델명, 라이선스, 컨텍스트 길이, VRAM/RAM 요구량과 30페이지 처리 성능
- **장애 정책:** 사용자 PC 종료 또는 터널 단절 시 timeout, 재시도 횟수와 사용자 메시지
- **증빙 보존:** 보존 위치, 기간, 접근 권한 및 삭제 책임자
