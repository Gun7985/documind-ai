# DocuMind AI MVP 요구사항

## 목표

사용자가 텍스트 기반 PDF를 안전하게 업로드하고 AI 분석 결과를 관리할 수 있는 웹 서비스의 최소 기능을 구현한다. 완성 후 짧은 기간 실제 배포하여 E2E 검증과 증빙 수집을 마치고 서비스를 종료한다.

## 기능 범위

### 인증 및 접근 제어

- Supabase Auth를 이용해 로그인과 로그아웃을 제공한다.
- Spring Boot가 JWT를 검증하고 모든 문서 및 분석 데이터의 소유권을 서버 측에서 확인한다.
- 한 사용자는 다른 사용자의 문서, 분석 결과 또는 이력에 접근할 수 없다.

### PDF 관리

- 텍스트 기반 PDF 업로드를 지원한다.
- 업로드 제한은 잠정적으로 파일당 10MB, 최대 30페이지로 한다. 구현 전에 실제 환경에서 검증하고 확정한다.
- 사용자는 자신의 문서 목록과 상세 정보를 확인하고, 제목을 수정하거나 문서를 삭제할 수 있다.
- 원본 PDF는 Supabase Storage의 비공개 버킷에 저장한다.

### AI 분석

- PDF에서 텍스트를 추출하고 요약, 핵심 포인트 및 키워드를 생성한다.
- 분석 상태는 `PENDING`, `EXTRACTING`, `ANALYZING`, `COMPLETED`, `FAILED`로 표시한다.
- 사용자는 실패하거나 완료된 문서를 재분석할 수 있으며 분석 이력을 확인할 수 있다.
- 재시도 횟수에는 제한을 둔다.
- 분석 실패 시 기술 내부정보나 비밀을 노출하지 않는 이해하기 쉬운 사용자 메시지를 제공한다.

### 검색 및 필터

- 문서 제목과 분석 키워드로 검색할 수 있다.
- 분석 상태 등 MVP에 필요한 조건으로 목록을 필터링할 수 있다.

## 비기능 요구사항

- 사용자별 데이터 격리를 서버 측에서 강제한다.
- 업로드, 분석 요청, 권한 거부 및 장애 경로에 최소한의 자동화 테스트를 둔다.
- 민감정보를 로그에 남기지 않고 API 응답에도 노출하지 않는다.

## 범위 밖

- 스캔 PDF 이미지의 OCR
- RAG 또는 벡터 검색
- 결제 및 구독
- 다중 문서 비교
- 상시 서비스 운영 및 수익화
